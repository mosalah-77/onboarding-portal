# Attribution

Figtree by Erik Kennedy is self-hosted under the SIL Open Font License 1.1. The Latin variable WOFF2 as served by Google Fonts and the licence are in `public/fonts/`. Source: https://github.com/erikdkennedy/figtree

The repository began with a vinext starter template. Its framework setup and build scripts are not my original work. The starter's hosting plugin, connector code, unused UI components and their packages have been removed. The package lock records the dependency versions, and installed packages carry their own licences.

The sample PNG is generated test data. The brief content, companies and people are fictional. Three of the demo names, Jackie Welles, Viktor Vektor and Silverhand Studio, are a nod to characters in Cyberpunk 2077. Nothing else from the game is used.

No code or assets from any employer or client project were used. The README describes how the project was made, including the use of AI assistance.
