# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Cloudflare Workers, React/TypeScript and D1 for records and private file bytes.

## Users

A made-up client answers a studio's questions about a new website. A made-up studio owner reviews the brief and approves one version. A visitor plays both by switching seats.

## Product Purpose

Teach and demonstrate onboarding from missing information to an accepted, versioned brief and handoff.

## Operating Context

Each visitor has an isolated run with two client workspaces. Answering, sending, asking for changes and approving one version are the main tasks.

## Capabilities and Constraints

Follow the approved spec. Identity is simulated; stored data and permissions are real. Synthetic data only. No AI, billing or external messages.

## Brand Commitments

Original interface and copy. No Halvern branding or proprietary material. Use Humanizer on published text.

## Evidence on Hand

This is an independent portfolio project with no claims of clients, adoption or measured savings.

## Accessibility & Inclusion

Keyboard operation, labels, linked errors, visible focus, readable contrast, mobile and zoom support.
